# BuildTrack (Valencia Construction Services)

Construction site progress + QA app. Panels: Admin (Super Admin / Admin), Engineer, Foreman, Client. Core feature: pins on uploaded blueprints.
This is the ONLY context file. Do NOT reference or touch anything from the "ebalik" project (its Supabase, keys, SMTP, OAuth). BuildTrack has its own Supabase project (ref in `.env.secrets`).

## Commands
- Deploy Edge Functions: `pnpm functions:deploy` (needs SUPABASE_ACCESS_TOKEN set in the terminal or `npx supabase login`; project ref is baked into the script)
- Dev `pnpm dev` (port 8443, strictPort) | Build `pnpm build` | Format `pnpm format`
- Migrations: the agent applies them through the **BUILDTRACK_MIGRATIONS** connector (`mcp__...__apply_migration` / `execute_sql`), ONLY after (1) `get_project_url` returns `https://ruimjlhsfpaezkgfphsz.supabase.co`, (2) `pnpm test:sql` passes, (3) the SQL file exists in `supabase/migrations/`. Afterwards: verify with read-only queries, run `get_advisors` (security), then update `docs/audits/migrations-log.md`, `docs/audits/sql/README.md` and the `sql/NNNN_*.md` doc. Destructive SQL (drop/delete/truncate of data) needs the user's approval first. Never use any other Supabase project or connector (E-BALIK_* stays disabled). Fallback: `pnpm db:status|db:apply` (token runner, `scripts/db-migrate.mjs`).
- Test cases live in `supabase/tests/NN-name.cases.mjs` (auto-loaded by `run-sql-tests.mjs`). Interactive UI (pan/zoom/drag) is verified in the browser with a temporary demo page under `src/dev/` + extra `*.html`, deleted afterwards.
- SQL tests: `pnpm test:sql` (in-memory Postgres via PGlite, applies all migrations, tests RLS/triggers as each role; database setup shared in `supabase/tests/harness.mjs`). Add tests for every migration.
- Load test: `pnpm test:load` (`scripts/load-test.mjs`, default 50 sheets / 5,000 pins / 300 inspections / 500 NCRs through the real triggers, times the app's queries per role). Run it after any RLS or query change.
- Editor math tests: `pnpm test:lib` (geometry + layer order in `src/lib/{geometry,layers}.ts`, pure TS, no deps). Keep layer rules identical to SQL `move_annotation_layer`.
- Type-check: `npx tsc --noEmit`
- If `pnpm install` fails with "Access is denied" in node_modules, an IDE (Antigravity) is locking it: close it or skip install.
