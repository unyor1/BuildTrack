8. 2D Blueprint Mapping
This should be one of the main features of BuildTrack.

The Engineer can place clickable areas/markers over the blueprint.

For example:

        FLOOR PLAN

 ┌─────────────────────────────┐
 │                             │
 │   ROOM A       ROOM B       │
 │    🟢           🟡          │
 │                             │
 │───────────────┐             │
 │   ROOM C      │   ROOM D    │
 │      🔵       │      🔴     │
 │               │             │
 └─────────────────────────────┘

Each marker represents a construction activity/location.

Example:

Room A

Activity: Wall Installation

Status: Completed

Progress: 100%

QA: Passed

Room B

Activity: Electrical Installation

Status: In Progress

Progress: 65%

QA: Pending
