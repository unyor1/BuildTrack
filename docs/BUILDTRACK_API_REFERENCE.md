# BuildTrack API Reference (Comprehensive)

**API Version:** v1.0  
**Base URL:** `https://api.buildtrack.com/api/v1`  
**Authentication:** Bearer Token (JWT)

See BUILDTRACK_ROADMAP.md for full endpoint specifications and examples.

Key endpoints include:
- Authentication (register, login)
- Projects (CRUD + analytics)
- Blueprints (upload, management)
- Progress Tracking (milestone pins)
- QA Defects (logging, tracking)
- Worker Management (timekeeping, biometric)
- Payroll (calculations, exports)
- Offline Sync (push/pull)
- WebSocket (real-time collaboration)

All endpoints support pagination, filtering, and role-based access control.

For detailed examples and request/response payloads, see BUILDTRACK_ROADMAP.md sections on API Endpoints.
