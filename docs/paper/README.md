- `buildtrack-evaluation-questionnaire.md`: researcher-developed questionnaire and technical review draft. Adviser review and trial administration remain pending.

Temporary PDF exports, page renders, extracted reference/layout metadata and the pre-edit manuscript backup remain local. They are not included in the documentation commit. No files were deleted to prepare the commit. Google Docs/Sheets edits are represented by their links, local sources and audit notes; a Git push does not publish native Google file revision history.
